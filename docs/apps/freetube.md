# FreeTube: agent rules

Moved from `AGENTS.md`. User guidance: [apps guide](../apps.md).

- The default installs FreeTube the same way as the Bitwarden fallback, as the user-scoped aarch64 Flathub app (`io.freetubeapp.FreeTube`).
- Leave FreeTube settings and `~/.var/app/io.freetubeapp.FreeTube/config/FreeTube` alone.
- The Syncthing FreeTube wrapper is not implemented yet (see [Syncthing](syncthing.md)).
