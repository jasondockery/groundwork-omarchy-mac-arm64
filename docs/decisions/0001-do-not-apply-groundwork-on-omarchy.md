# 0001. Do not apply Groundwork on Omarchy

`groundwork-mac` remains the setup for Mac, WSL, and containers. On Omarchy, do not run `chezmoi apply` from that repo. The learning curriculum stays in the original [Groundwork site](https://jasondockery.github.io/groundwork/) for now; use [this repo's shortcut guide](../keybindings.md) for the Omarchy keymap. The `core/` submodule stays a read-only checkout. Setup and update check it out to read shared specs; this decision does not stow or apply it as machine configuration. Do not copy curriculum pages into this repo.

`groundwork-mac` replaces `~/.config/tmux/tmux.conf`, replaces Git config, and switches the login shell toward zsh plus Linuxbrew. Its tmux prefix is now Ctrl+Space, with Ctrl+B as the second prefix, which matches Omarchy. Omarchy still keeps its own tmux file, desktop shortcuts, and shell. Do not copy the Mac tmux config here. User overrides stay in `~/.config`. Leave `/usr/share/omarchy` alone.

Bring over a single habit by hand, into a file this repo already manages, when it is not an Omarchy default.

The one git-default exception is `grep.threads` set to 4. Agents run many git grep searches, and upstream starts one worker per core. `groundwork-mac` sets that cap in the shared Unix gitconfig, which this repo does not apply. Setup and update call `scripts/groundwork-grep-threads.py`, which writes only that setting, with a short reason comment, into the Groundwork-owned include `~/.config/groundwork/grep-threads.gitconfig`. It rewrites that file when the text differs, so another key or a missing comment does not remain beside a parsed value of 4. A second run of the exact text does not rewrite it. It includes the file from `~/.config/git/config` when that path is absent, and it removes every include path whose file is named `grep-threads.gitconfig`, including repeated copies, so a later stale copy cannot override the cap. Other include paths are left alone. No other git default is copied.
