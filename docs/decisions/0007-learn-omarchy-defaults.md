# 0007. Learn Omarchy's built-in desktop and development conventions

Omarchy (`omacom/omarchy` `quattro`) owns desktop navigation and developer-tool defaults. Keep its Hyprland bindings, tmux config, terminal, editor, shell, and AI-agent integrations active instead of copying the `groundwork-mac` setup onto Omarchy. Both trees use `Ctrl+Space` as the tmux prefix, and `Ctrl+B` remains available. `groundwork-mac` also installs Omarchy's no-prefix chords (`Alt+Enter`, `Alt+Shift+Enter`, `Alt+Escape`, `Ctrl+Alt+Arrow`, `Alt+Left`, and `Alt+Right`) so the same terminal habits work on every Groundwork OS. Omarchy still uses its own tmux config and desktop shortcuts, including `Super+Space` and `Super+K`. On this installer path those menus work because [omarchy#14553](https://github.com/omacom/omarchy/pull/14553) is in `quattro`; [omarchy-mac#707](https://github.com/omacom/omarchy-mac/issues/707) and [PR #710](https://github.com/omacom/omarchy-mac/pull/710) cover only the omarchy-mac `quattro` path. This repo does not install Groundwork's Mac keymap, Karabiner rules, or shell config.

The repo intentionally layers Magic Trackpad overrides in `packages/hypr/.config/hypr/input.lua` on top of Omarchy's `/usr/share/omarchy/default/hypr/input.lua`, and makes Caps Lock Escape on tap, Control while held through keyd. The overlay lists only real diffs: traditional scrolling, tap-to-click, three-finger drag, higher pointer sensitivity (`0.35`), and a slower touchpad scroll factor (`0.2`). Two-finger right-click already matches Omarchy and stays out of the file. Omarchy defaults to natural scrolling, so the explicit traditional-scrolling override remains. Sensitivity and scroll factor are starting values; tune them live with `hyprctl reload`. These are opinionated defaults for every user, not machine-specific settings. `./install.sh --without-keyd` skips keyd setup without altering any existing configuration or service. See [decision 0003](0003-caps-lock-via-keyd.md) for Compose, verification, and recovery. A shell plugin may later write `~/.config/hypr/mouse.lua` or `omacontrol.lua` and load it after this file. When either sets `touchpad.natural_scroll` differently, the one Hyprland loads later wins, and apply names that file. See [decision 0010](0010-omarchy-plugins-from-shared-list.md).

Learn the upstream workflow from the [Omarchy hotkey guide](https://github.com/omacom/omarchy/blob/quattro/manual/07-hotkeys.md) and [terminal guide](https://github.com/omacom/omarchy/blob/quattro/manual/15-terminal.md). These cover `Super+K` for desktop bindings, `Super+Alt+K` for tmux, `tdl`/`tds`/`tdlm`/`tsl` AI layouts, and Herdr alongside tmux. The Apple Silicon edge image includes tmux, Neovim, Herdr, and the edge Omarchy packages.

Treat those shipped conventions as the starting point, then make deliberate personal changes after learning them. Do not describe them as universal AI-developer habits; they are Omarchy's documented defaults and DHH's project's supported workflow.
