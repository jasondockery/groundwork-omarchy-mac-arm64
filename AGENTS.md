# Agents

This repo is a personal layer for Omarchy on Apple Silicon (aarch64). It is meant to be shared. Read these files before changing anything:

- The original `groundwork` curriculum and north star for shared learning material. Curriculum stays there for now; the optional `core/` submodule is a read-only reference, not a setup prerequisite. Do not copy those pages into this repo.
- `README.md` for what this environment installs and how.
- `docs/status.md` for the current state of the reference machine.
- `docs/decisions/` for choices that are already made.
- `docs/keybindings.md` and `docs/remote-access.md` for first-run learning and private access.

Shared engineering guidance belongs to [Compass](https://github.com/jasondockery/compass). Consult its current `COMPASS.md` and applicable skills for substantial engineering changes instead of inventing a competing local doctrine. This small repo currently links to that authority; it does not claim a receipt-verified Compass projection. Dependency policy extends the shared [renovate-config](https://github.com/jasondockery/renovate-config) preset; configuration alone does not prove central-runner coverage.

## Rules

- The desktop comes from `omacom/omarchy` (`quattro`), packaged as `omarchy-dev` from `pkgs.omarchy.org/edge`. Apple Silicon support is the `omarchy-mac` and `omarchy-mac-boot` packages from `omacom/omarchy-mac-pkgs`. `omacom/omarchy-mac` tracks hardware; its own `quattro` branch is not what the installer uses. Do not copy stock Hyprland templates, shell aliases, tmux config, or git defaults into this repo.
- Preserve Omarchy's desktop navigation, tmux, terminal, editor, shell, and AI-tool defaults. Do not add a replacement keybinding or tmux config unless Jason explicitly asks for it. The trackpad override and keyd Caps Lock tap-Escape/hold-Control default are intentional. `--without-keyd` skips keyd setup without disabling an existing service. See `docs/decisions/0007-learn-omarchy-defaults.md`.
- Do not run `chezmoi apply` from `groundwork-mac` on an Omarchy machine. See `docs/decisions/0001-do-not-apply-groundwork-on-omarchy.md`.
- `./install.sh` stows only `packages/hypr`, installs Herdr/Tailscale/keyd, and installs Cursor when `cursor` is absent, through `omarchy-install-cursor` on older Omarchy Mac builds and otherwise `omarchy pkg add cursor-bin`. An existing `cursor` command is kept. When `~/.config/Cursor/argv.json` has no `password-store`, setup adds `gnome-libsecret` and leaves every other key unchanged. It ensures missing native AI providers through Omarchy's declared mise tools, enables the Tailscale and keyd daemons, and reconciles the newest official T3 Code Nightly CLI on each run, including existing stable installations. On kernels with pages larger than 4 KiB it keeps a Nightly that already starts and otherwise pins `0.1.2-nightly.20261021.3499`; `update-all` checks every ELF file in a newer build with `readelf -lW`, smoke-runs that candidate under bubblewrap with a scrubbed environment and a timeout (a missing bwrap skips that run with a warning and does not execute it), installs exactly the version whose `--version` matches, remembers misaligned builds and signal/`PinnedRuntimeInstallError` failures in `t3-rejected.json`, warns without remembering timeouts or transport errors, reports a failed `t3 update` that leaves a working install as a warning, and repairs a T3 that no longer starts (pingdotgg/t3code#23433). It backs up a different existing keyd config and reloads the mapping on every default install. It does not stow `core/`, it does not write `/usr/share/omarchy`, and it installs Blip only when `--with-blip` is passed. Tailnet sign-in stays interactive and local. Shared Tailscale policy lives in `groundwork-core/docs/tailscale.md`; this repo owns only the Omarchy service and enrollment steps.
- The reference M1 Mac mini migrated on 2026-10-17 through the Omarchy Mac Installer and signed edge catalog (installer 2.2.0 and image `omarchy-mac-edge-2026.10.14-79f8e36b977f` on that day). Apple Silicon has only an edge channel. See `README.md` and decision `docs/decisions/0002-edge-via-omarchy-mac-installer.md`. This repo only applies user settings and never installs the OS. Keep the actual installed version in machine/status notes.
- Upstream bugs stay upstream. Desktop bugs go to `omacom/omarchy`, installer or image bugs to `omacom/omarchy-mac-installer`, and hardware bugs to `omacom/omarchy-mac`. Link to them. Do not refile them here.
- Config that is stowed must work on any Apple Silicon Mac: Mac mini, MacBook Air, and MacBook Pro, M1 and later. `./install.sh` refuses a machine that is not aarch64. Machine-specific facts go in `docs/machines/`.
- Never commit private keys, account emails, employer or org remotes, Wi-Fi names, or Tailscale addresses. Public SSH keys do not belong here either. Put account-specific Git and SSH config on the machine, outside this repo. Do not publish while an old commit still contains any of that.
- `packages.txt` is optional Arch packages. Do not add Linuxbrew.
- The default also ensures Obsidian and Bitwarden CLI (`bw`), reuses a native Bitwarden desktop when present, and otherwise installs its user-scoped aarch64 Flathub app. It installs FreeTube the same way (`io.freetubeapp.FreeTube`) and leaves FreeTube settings and `~/.var/app/io.freetubeapp.FreeTube/config/FreeTube` alone. `docs/apps.md` owns sign-in, Flatpak updates/removal, and cross-platform notes guidance. `scripts/seed-obsidian.py` seeds Vim mode only when app settings are absent; never automatically move notes, replace existing settings, enable broad community plugins, or enroll a cloud account. `GROUNDWORK_OBSIDIAN_VAULT` selects an actual local folder. Blip (`nixfred.blip`) is an opt-in iMessage client (`./install.sh --with-blip`, off by default, decision 0011). A default run and `--without-blip` leave an existing Blip install alone. Install it from git with `omarchy plugin add`, and move it into the shared plugin list once that list supports git-URL sources and per-entry opt-in. The installer does not run `blip-setup` or record a gateway name. Its bun preflight downloads the mise-selected `bun-linux-aarch64` release over https, verifies `SHASUMS256.txt`, and calls the T3 `load_alignments` helper before `omarchy-install-dev-env`. Session-restoration plugins remain outside the defaults.
- For installed Chromium, register only the official Bitwarden extension through its external manifest under `/usr/share/chromium/extensions`, preserving different previous manifests with numbered backups. Do not impose forced-install policy, rewrite profile databases, or authenticate accounts. Browser approval and effective autofill remain first-use acceptance.
- Default desktop sharing uses WayVNC via the Groundwork-owned user service/helper. Generate and preserve local credentials, wait for an online Tailscale IPv4 address, and bind only that address. When its unit, helper, or WayVNC config changed and `WAYLAND_DISPLAY` is unset (SSH or cron), an inactive unit stays stopped and the restart record is cleared. When `WAYLAND_DISPLAY` is set, the unit restarts even if it is inactive. Print the session-drop warning only when a restart actually runs. See `docs/remote-access.md`. Never expose legacy Apple-compatible VNC authentication on LAN/all interfaces, publish credentials, disable the lock screen, or claim pre-login/headless recovery. `--without-screen-sharing` leaves an existing setup alone; shared port policy stays in Core. WayVNC's private keymap makes Apple Screen Sharing's Command follow existing Super bindings and Option follow existing Alt bindings. Leave Omarchy's global keymap and attached keyboards unchanged.
- Shell plugins come from the shared groundwork-core list (`omarchy/plugins.json`) and are applied once by `scripts/omarchy-plugins.py` after the Hyprland reload. `GROUNDWORK_PLUGIN_LIST` overrides that https source. `omarchy-plugins.exclude.json` and `~/.config/groundwork/omarchy-plugins.exclude.json` skip ids, each with a reason. `update-all` updates listed checkouts; `groundwork-update` leaves their revisions unchanged. Do not name plugin ids in this repo, do not Stow `~/.config/omarchy/shell.json`, and do not re-enable a plugin whose directory already exists. If `mouse.lua` or `omacontrol.lua` sets `touchpad.natural_scroll` differently from the stowed `input.lua`, the file loaded later wins. If `hyprland.lua` does not load that file, the stowed `input.lua` still applies. See `docs/decisions/0010-omarchy-plugins-from-shared-list.md`.
- Local inference is off unless `./install.sh --with-local-inference` is passed (decision 0012). That installs Omarchy edge `ollama` and `ollama-vulkan`, plus `vulkan-tools` when `vulkaninfo` is missing. It downloads no model and does not enable `ollama.service`. GPU use is unverified until `scripts/verify-local-inference.py run` is executed on the machine. Shared model policy stays in groundwork-core#19. `omarchy-mlx` and macOS MLX are not installed.
- Run `bash -n install.sh scripts/apply-layer.sh scripts/migrate-from-groundwork.sh` and `python3 -B -m unittest discover -s tests -v` before handing off installer changes. Fixture success is not live desktop/input or cross-machine acceptance. Never mark machine status as installed or authenticated from package presence alone.

## Layout

| Path | Role |
|---|---|
| `core/` | Optional read-only reference submodule. Curriculum stays in `groundwork` for now. Not applied to the machine. |
| `packages/hypr/` | Stow package. Personal Hyprland overrides only. |
| `keyd/default.conf` | Default Caps Lock tap = Escape, hold = Control. Skip setup with `./install.sh --without-keyd`. |
| `docs/decisions/` | One decision per file. Update the decision instead of appending a journal. |
| `docs/status.md` | Replace this when the reference machine's state changes. |
| `docs/machines/` | One file per computer. |
| `scripts/omarchy-plugins.py` | Applies the shared Omarchy shell-plugin list. |
| `scripts/verify-local-inference.py` | Opt-in M1 GPU check for Ollama Vulkan. A passing run on hardware is the record; the repo does not contain one. |
| `docs/local-inference.md` | Apple Silicon install, proof, update, stop, and removal. |
| `omarchy-plugins.exclude.json` | Plugin ids this layer skips, each with a reason. |
